# Food image credits

All images are bundled in `frontend/assets/images/`; the running app does not fetch these photos from third-party servers.

The 200 restaurants and their menus are fictional. The current menu uses 135 separate generated recipe images, not verified photographs of a delivered meal. Different recipes no longer share generic cuisine images. Regular and sharing variants intentionally share an image. Images are repeated across restaurant branches. Menu descriptions and dietary flags describe the recipe; a representative image is not dietary guidance.

The frontend resolves historical emoji references and saved-cart item names to bundled photographs. The demo seed updates image fields for existing seeded IDs without changing their prices, availability, names, accounts or orders.

## Current recipe artwork — 17 October 2026

All 135 `dish-*.jpg` images were created individually with the built-in image generator for the named QuickBite recipe. Each prompt uses the menu name, cuisine, recipe description and vegetarian flag. Art direction: natural food photography, soft daylight, warm ivory tabletop, appropriate plate/bowl/glass, visible ingredients, no text or branding. The full prompt set and output filenames are recorded in `FOOD_IMAGE_PROMPTS.json`.

The menu name determines the recipe image. Regular and sharing versions, and the same named recipe served by another fictional kitchen, intentionally share that recipe asset. Restaurant covers draw from recipes on that kitchen's menu. The generated images are illustrations, not documentary photographs of real restaurant products.
