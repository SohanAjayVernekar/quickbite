QuickBite update package

Apply these updates to your existing QuickBite project:
1. Extract this ZIP into the root of your existing project folder.
2. Allow it to overwrite the matching files.
3. Open the frontend folder in VS Code and run the project as usual.

This package contains the admin dashboard/navigation improvements and the
product-name image mapping/framing updates. It does not contain the full app or
image/model assets; those remain in your existing project folder.
